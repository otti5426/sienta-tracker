# SIENTA Tracker（車の燃費アプリ）

## アプリを開く

**https://otti5426.github.io/sienta-tracker/**

- フォルダ内の `アプリを開く.url` をダブルクリックでも開けます
- スマホはこのURLを開いて「ホーム画面に追加」しておくとアプリのように使えます

## 記録のしくみ

データはブラウザのローカル保存（localStorage）＋ `data-05873f399d42.json` の2本立てです。

- 端末で入力した記録 … その端末のブラウザに保存される
- `data-05873f399d42.json` … PCで管理する正データ。アプリは**起動時に自動で読み込み、足りない記録だけ追加**する

同じ記録が二重に入ることはありません。ただし**削除は同期されません**（端末で消しても `data-05873f399d42.json` に残っていれば次回また入ります）。消したい記録は `data-05873f399d42.json` 側から消してください。

### 記録の入れ方は2つあるが、対等ではない

| 入れ方 | 保存先 | 他の端末へ | 消える危険 |
|---|---|---|---|
| アプリに直入力 | その端末のブラウザだけ | 行かない | あり |
| `取込/` にCSV → `取り込む.bat` | 正データ | 全端末に届く | なし |

**アプリへの直入力は正データに戻ってこない。** 直入力だけで済ませていると、その端末のブラウザデータが消えたときに一緒に消える（2026-08-11以降そうなっていた）。

おすすめの運用は「給油のたびはアプリに直入力 → ときどき正データに吸い上げる」。吸い上げ方は次のとおり。

1. アプリの 設定 → 「バックアップ書き出し」でJSONを保存
2. そのファイルを `取込/` に入れて `取り込む.bat`

全件入ったファイルをそのまま入れて構わない。重複は自動で弾かれ、新しい記録だけが足される。
アプリに入力せずCSVだけで管理する運用でもよい。

## PCからまとめて取り込む手順

同じCSVを編集し続けるのではなく、**新しいファイルを `取込/` に置く**。取り込んだファイルは `取込済み/` に日時付きで移動するので `取込/` は毎回空になる。

1. `取込/` フォルダに CSV か バックアップJSON を入れる
2. `取り込む.bat` をダブルクリック
3. `data-05873f399d42.json` が更新され、GitHubへ自動で送信される
4. スマホでアプリを開くと自動で反映される（反映されない時は 設定 → 自動同期 → 「今すぐ同期」）

GitHubに送らず手元だけで確認したい時は `取り込む_送信なし.bat` を使ってください。

### 取込フォルダに入れられるファイル

| 種類 | ヘッダー |
|---|---|
| 給油ログCSV | `日付,走行距離(km),給油量(L),金額(円),満タンフラグ(1:はい/0:いいえ),冬タイヤフラグ(1:はい/0:いいえ)` |
| メンテナンス記録CSV | `日付,区分,金額(円),メモ`（区分は 洗車／タイヤ／点検／その他） |
| バックアップJSON | アプリの「バックアップ書き出し」で出したファイル |

拡張子とヘッダーから種類を自動判別します。取り込んだファイルは `取込済み/` に日時付きで移動します。

## フォルダ構成

| 場所 | 中身 |
|---|---|
| `index.html` `app.js` `styles.css` `sw.js` `manifest.json` | アプリ本体（GitHub Pagesで公開） |
| `data-05873f399d42.json` | 正データ。ここが同期の元（公開リポジトリなので推測されにくい名前にしてある） |
| `取込/` | ここにCSVを入れる |
| `取込済み/` | 取り込み済みファイルの控え |
| `バックアップ/` | 実行のたびに `data-05873f399d42.json` のスナップショットを自動保存 |
| `tools/merge_data.py` | 取り込み処理の本体 |
| `資料/` | スクショ・エビデンス類 |
